Example Script

Here's an example of a DevHub automation script:

# Auto-label pull requests based on files changed name: Auto Label PRs on: pull_request: types: [opened, synchronize] jobs: label: runs-on: ubuntu-latest steps: - name: Label based on paths uses: actions/labeler@v4 with: repo-token: ${{ secrets.GITHUB_TOKEN }} configuration-path: .github/labeler.yml
