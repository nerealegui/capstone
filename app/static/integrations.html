API Integration

Build custom integrations using our comprehensive REST API:

curl -X POST https://api.devhub.com/v1/integrations \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "service": "slack", "webhook_url": "https://hooks.slack.com/...", "events": ["push", "pull_request"] }'
