# Usage Guide - GitHub Pages Site

This directory contains the GitHub Pages site for the Intelligent Business Rule Management usage guide.

## Structure

- `index.md` - Main homepage with overview and introduction
- `setup.md` - Detailed setup instructions for Docker and manual installation
- `usage.md` - Step-by-step usage guide with examples
- `troubleshooting.md` - Common issues and solutions
- `_config.yml` - Jekyll configuration
- `_layouts/default.html` - Default page layout with Primer CSS styling

## Deployment

The site is automatically deployed to GitHub Pages when changes are pushed to the main branch via the GitHub Actions workflow defined in `.github/workflows/pages.yml`.

## Styling

The site uses GitHub's Primer CSS for consistent styling and familiar GitHub UI patterns.

## Access

Once deployed, the site will be available at: https://nerealegui.github.io/capstone/
